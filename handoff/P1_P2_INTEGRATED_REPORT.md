## 2. P1 — 묘사 전 세계 진행 · 후속 묘사 은퇴 · 비용 정합

### 2-1. 세계 진행(#2·#1)

| 결정 | 구현 |
|---|---|
| Q1/D1 묘사 전 진행 | 판단층위 런타임 스키마 `action_intent.action_minutes`(0~240, 초과 240·잘못된 값은 시간 없음)로 이동·대기가 아닌 행동도 묘사 **전**에 코드가 시간을 진행. 추출 `extra_minutes`는 DYNAMIC에서 거부(이중 가산 없음) |
| D2 같은 분 선후 | 정본 인과는 엔진 그대로, 남은 자유 경합만 지시층위 `tie_order` 선택 — 무효면 정렬 첫 순서(결정적) |
| D3 같은 턴 인지·표시 | 묘사 후 노출·식별·발견은 같은 커밋 인지. 본문이 표현하지 못한 신호는 `world_pending_signals`로 다음 본문 '그사이'에 전달(3회 미전달 시 진단 은퇴). 표시 갱신은 커밋 뒤·다음 선언 전 |
| D4 직접 반응 | 접근 지급·사용 사실을 같은 턴에 평가(`evaluated_same_turn`), 다음 턴 재평가 없음 |
| #1 후속 묘사 | `_generate_continuation`·`ForegroundContinuationPlan` 삭제 — 한 턴 = 한 본문 |

필수 서사 보장 수준: 프롬프트 지시 **적용** · 추출 판독(`represented_signals`) **적용** · 결정적 문자열 검증·송출 전 버퍼링 **미적용** · 의미 보장 **아님**.

### 2-2. 비용(#8)

- TTS: 오디오 가공 전 usage 기록, 타임아웃 뒤 늦은 응답 1회 관측, 응답 없음은 `cost.unknown`(0원 이벤트를 만들지 않음).
- CostEvent 통계 차원(시나리오·revision·모드, 멱등 지문에서 제외).
- 턴 비용 보고: 항목 모델별 단가로 분해, 원장 원가·운영자 부담·예상 대비 표시. 플레이어 예상 비용 UI 형식은 불변.
- 예측: 원장 통계(시나리오 → 전역 → 기본값)·부가 호출·TTS 가시 본문.
- 플레이어 청구(Settlement → InkTransaction)는 불변.

### 3-2. 그 밖의 항목

- **#9 TTS 실효**: 두 게이트(`tts_enabled`·`media_flags["tts"]`)를 AND로 일원화. 상태판에 "ON / 미연결 / OFF" 표시. `!tts생성`(오너 도구)은 현행 유지.
- **#3 저장 프로필**: 불러온 프로필이 바뀌지 않았으면 저장 버튼 숨김(방문·원복은 변경 아님). 저장은 확인 1회 뒤 새 프로필(원본 불변). 판정 근거 `loaded_profile`은 진행 기록과 함께 영속.
- **#4 대화형 메시지**: 세션 생성·캐릭터 생성·초기 지식·시작 틀 안내를 content로, 정형 필드는 카드로. 초기 지식 영수증은 content 줄로 옮기고 옛 Embed 푸터도 계속 읽음.
- **#7 마스터 슬롯**: `assets/master/manifest.json` 6슬롯(남·여 × 기본·경고·긍정). 미제작(null) = 공용 로딩 이미지(로그 없음), 파일 이상 = 오류 이미지 + 슬롯당 1회 로그. 공용 이미지 2종 `assets/indaim_loading_neutral.webp`·`assets/indaim_error_neutral.webp`는 번들 원본 그대로. **원화 6종 미제작은 정상 상태**입니다.
