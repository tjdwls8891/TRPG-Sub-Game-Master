### 4.1 원칙과 재해석
- **connected는 구간이 아니다**(H03). 234쌍을 하나씩 판정해 구간을 사람이 저작했다(표 B). 역방향을 자동으로 만들지 않았다 — 비대칭 71쌍도 각각 "같은 길의 오르내림·같은 건물 계단" 등 사유를 적고 양방향으로 저작했다.
- **남항 중공업 연대 노드 = 방음벽 바깥 전면**(이미지 `영도조선소외부.png`과 일치). 세계관 6.1.2.1 "장벽의 유일한 출입구 = 제1방어선"에 따라 전면→내부 방 직결 9쌍을 **재경로**(제1방어선 → 수습대 집결지 → 조선소 내부 허브)로 바꿨다. 침입 경로는 외벽 배관→옥상 환기팬(철망) · 하수도→폐수 처리조(철망).
- **해련 자치 마을**: 지상 출입구는 접이식 사다리뿐(6.2.2.1), 후방은 벌목 지대 함정선(6.2.3) → 산복도로·능선·봉래산·약수터 직결 5쌍 재경로.
- **조도**: 방파제 → 다중 검문소 → 안쪽(6.3.3.1). 방파제→사령부 직결 미저작.
- **미저작 2쌍**: 아치 방파제–조도 방위 사령부(검문소 경유 강제), 봉래산–폐채석장(채석장은 남동 해안 쪽, 봉래산 권역 중심과 2km 이상 — 직결 근거 없음).

### 4.3 보정값
- 이동 방식 `walk` **48 m/min**(은밀 기동). 세계관 1.3절 거점 간 시간과 대조:

| 구간 | 세계관 | 초안(실제 최단) |
|---|---|---|
| 남항 → 해련(오르막) | 40~60분 | 61분 |
| 해련 → 남항(내리막) | — | 55분 |
| 남항 → 중리 | 70~90분 | 68분(남쪽 부두·물양장 해안 경로) |
| 해련 → 중리 | 50~70분 | 67분 |
| 중리 → 조도 | 해안로 ~1km + 방파제 400m | 36분 |
| 해련 → 조도 | 90~120분 | 84분 |

- 거리 = 좌표 스케치 직선거리 × 지형 굽이 계수, 시간 계수 = Tobler 보행 함수(경사) × 지형 계수(하수 관로 1.8·사다리 2.5·외벽 타기 3.0·미로 1.3 등) — 오르막·내리막 비대칭은 `reverse`로 기록. 방향 힌트(`route_hint`) = 좌표 방위 + 경사어 + 지형어. 고정 지연: 사다리 2분·맨홀 2분·관로 철망 3분.
- 좌표 스케치(x·y·고도)는 워크북 `geo.py`에 전부 있다 — **실측 지도가 아니다**.
